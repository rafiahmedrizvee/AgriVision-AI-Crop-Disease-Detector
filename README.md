
# AgriVision AI — Crop Disease Detector

## Project Overview
AgriVision AI is a computer vision application that classifies selected plant leaf images into predefined categories and provides general crop-care guidance in Bangla.

## Problem Statement
Farmers may find it difficult to recognize visible signs of plant disease early. This project explores how image classification can help users understand possible leaf conditions.

## Key Features
- Upload a plant leaf image
- Predict a supported leaf category
- Display model confidence
- Provide Bangla crop-care guidance
- Access the application through a web interface

## Tech Stack
- Python
- TensorFlow / Keras
- MobileNetV2
- FastAPI
- React
- Tailwind CSS
